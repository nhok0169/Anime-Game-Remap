# Dump to Mod Converter

[![Static Badge](https://img.shields.io/badge/Python-254F72?style=for-the-badge)](https://www.python.org/downloads/)
[![Static Badge](https://img.shields.io/badge/Jupyter%20Notebook-F37726?style=for-the-badge)](https://jupyter.org/)

<br>

Converts dumped mods from a 3dmigoto frame analysis into the corresponding binary formats for a mod

<br>

> [!NOTE]
> One of the reasons we used a notebook for these converters are an adhoc, one-time process. The other reason is to
> give a bit more transparency on how the data in a mod is structured

<br>

## How to Run
1. Go to the corresponding notebook:

| Game | Notebook Location |
| ---- | ----------------- |
| GI | [GIDumpToModConverter.ipynb](GI/GIDumpToModConverter.ipynb)

<br>

2. Follow the instructions on the selected notebook and run the codeblocks
