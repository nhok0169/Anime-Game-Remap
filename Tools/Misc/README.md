# Misc

Scripts the `AI Agent Help/` guides refer to that were written next to the mods they operate on,
on the maintainer's machine (`E:\Computer\Games\Wuthering Waves Mods\Importer\GIMI\...`), copied
here so an agent on another machine can read and run them. **The copies under `Importer/GIMI/`
are the live ones the maintainer runs; when the two differ, the live one is newer.** Everything
here runs on Windows or Linux / WSL (a Windows-form path argument is translated to `/mnt/<drive>/...`
on Linux), and finds the API through `AG_REMAP_REPO` or the repo's own layout.

| `Linux/buildTests.sh <Test> ...` | compile and run named `core/tests/*.cpp` standalone tests on Linux against the native build tree | [Testing](../../AI%20Agent%20Help/Testing/CLAUDE.md) |
| `Diagnostics/runCompiled.py <mod folder>` | fix a folder through the COMPILED tables alone and print every stats bucket -- the compiled half of an A/B against a prototype (fix a scratch copy with each, diff the folders) | Creating Remaps' "Yelan is COMPILED now" |
| `Diagnostics/slotTextures.py <mod folder> ...` | **the table to read before reasoning about textures at all**: per draw slot (a `TextureOverride` with a `match_first_index`), whether the mod declares any `ps-t` -- and so whether that slot renders with the MOD's art or the GAME's -- and then, if the folder has been fixed, what each draw of each remapped section binds. Reports; does not decide | Creating Remaps' "A `TextureOverride` binds registers only for the draw its hash matches" |
| `Diagnostics/drawCoverage.py <fixed folder> ...` | every remapped section's draws with their `if` DEPTH, flagging `auto` stacked on an explicit range, and a part drawn only from inside a toggle. **Depth is the point** -- a check that `.strip()`s the line cannot see nesting, which is what let a fix ship with the eyes on one toggle | Creating Remaps' "A target object several components merge onto is not one draw" |
| `Diagnostics/fixCallPaths.py <fixed folder> ...` | does any path call `NNFix` / `ORFix` twice **over one set of bindings**? They are involutions, so the second undoes the first and the model renders flat green. Counts per path per BINDING GENERATION -- an exclusive `if` / `else if` chain is one call, and a `ps-t` rebinding resets the count | Creating Remaps' "The fix libraries are involutions" |
| `Diagnostics/check_dangling.py <fixed folder>` | does every `filename =` a fixed `.ini` names exist on disk? A section diff compares `.ini` TEXT, so a resource the run never produced -- or produced and deleted -- diffs perfectly and is a missing mesh in game. Skips `DISABLED` files | Creating Remaps' "The A/B diff cannot see a missing file" |
| `Diagnostics/check_sections.py <fixed folder>` | the companion shape: does every `<register> = Resource...` name a section the FOLDER defines? A reference with no section has no filename for `check_dangling` to follow, so it passes there -- CherryHuTao's body drew with no light map that way. Pools defined names per folder, since a merge splits its resources across files | same |
| `Diagnostics/cmp_binaries.py <old tree> <new tree>` | compare every generated `.buf` / `.dds` / `.ib` of two fixed trees by content hash, enumerating BOTH sides so a file only one produced shows up. Matches the generated-name markers anywhere in the name -- an edited texture's name ends in a hash, and an `endswith` test once skipped every one of them | Creating Remaps' "A texture edit's output file is named with two hashes" |
| `Diagnostics/fixUndoCycle.py <original mod> <scratch>` | fix a scratch copy, UNDO it, and require every `.ini` back to the original section by section -- no leftover or lost sections, no `remap` text -- after reporting whether each `...Hide` section landed inside the remap block. An undo only takes what a fix wrote inside its block, so a template writing outside it passes every other check and still hides a component of the unmodded skin after undo | Creating Remaps' "Undo is only as complete as what the fix wrote INSIDE its block" |
| `Diagnostics/abIni.py <folder A> <folder B>` | A/B two fixed folders' `.ini` files SEMANTICALLY -- every resource reduced to the md5 of the file it names, `if`/`endif` dropped, key order kept. **Byte-identical buffers say nothing about the `.ini`**: one run had perfect buffers and `HashNotFound` in every section | Creating Remaps' "Byte-identical buffers say nothing about the `.ini`" |
| `Diagnostics/uvIsland.py <mod folder> <Texcoord.buf> <tex.dds> <out.png>` | crop the UV island an object occupies out of a texture and save it as a PNG, vertices marked, so it can be **looked at**. Refuses to guess the texcoord stride when more than one layout gives UVs in [0, 1] (they routinely do) -- pass `--stride` | Creating Remaps' "When the symptom is on a texture, crop the UV island and look at it" |
| `Diagnostics/purpleSlot.py <mod folder> --component <C>` | rebind ONE register of one target component's remapped sections to a flat magenta texture it writes itself (an uncompressed DDS -- no Compressonator, no Pillow DDS writer), backing up each `.ini`; `--off` restores them. **The answer does not depend on being right about anything**: the slot turns magenta and that section is what draws it, or it does not and the section is not | Overview's "When you cannot tell what a draw is using" |

Nothing tests this folder; run a script before you change it (see
[Tools](../../AI%20Agent%20Help/Tools/CLAUDE.md)). The `YelanExperiments/` scripts carry absolute
paths from the maintainer's machine near their top -- they are reference, not tooling.
