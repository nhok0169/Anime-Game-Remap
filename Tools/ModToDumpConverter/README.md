# Mod to Dump Converter

[![Static Badge](https://img.shields.io/badge/Python-254F72?style=for-the-badge)](https://www.python.org/downloads/)
[![Static Badge](https://img.shields.io/badge/Jupyter%20Notebook-F37726?style=for-the-badge)](https://jupyter.org/)

<br>

Converts the binary mod files into the collected dump files from a 3dmigoto frame analysis so that the mod can used in Blender

<br>

> [!NOTE]
> The converters are made using Jupyter Notebooks to give a bit more transparency on how the data in a mod is structured

<br>

## How to Run
1. Go to the corresponding notebook:

| Game | Notebook Location |
| ---- | ----------------- |
| GI | [GIModToDumpConverter.ipynb](GI/GIModToDumpConverter.ipynb)

<br>

2. Follow the instructions on the selected notebook and run the codeblocks
